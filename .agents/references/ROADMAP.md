# Roadmap

> Generated by Sauron from the discovery interview. Treat as the source of truth for this project.

## Milestone 1: Milestone 1: Rubberband binary provisioning
Wire the external rubberband CLI binary into the existing setup wizard / model downloader flow so pyrubberband has a runtime dependency to call, without bloating the installer.

  - **Add rubberband binary to model_downloader.py** _(claude)_ — Extend app/setup/model_downloader.py to download and verify the platform-appropriate rubberband CLI binary (Windows build) into the app's local binaries directory, following the same download/verify/progress-callback pattern already used for other model assets in that file.
  - **Wire rubberband download into setup_wizard.py UI** _(antigravity)_ — Add a step/checkbox in the setup wizard for downloading the rubberband binary, matching the existing wizard step pattern for other model downloads.

## Milestone 2: Milestone 2: Humanizer DSP stage (pitch drift + breath blend-back)
Implement the core new audio processing stage: pyrubberband-driven micro-pitch drift and automatic residual breath/noise blend-back, inserted after the existing enhance pass + QA-gated blend in vocal_chain.py.

  - **Implement pitch-drift humanizer function** _(claude)_ — New module app/core/humanizer.py implementing pyrubberband-based micro-pitch drift with an LFO-driven depth/rate mapping from a single 0-100% intensity parameter.
  - **Implement automatic breath/noise blend-back** _(claude)_ — Add a function that blends back a fixed, automatic amount of the residual signal left over from BS-RoFormer stem separation, to restore natural breath/friction detail.
  - **Insert Humanizer stage into vocal_chain.py pipeline** _(claude)_ — Wire apply_pitch_drift and apply_breath_blend into vocal_chain.py's existing pipeline, positioned after the enhance pass + QA-gated blend, before the signal is handed to remix_master.py.

## Milestone 3: Milestone 3: QA gate metric additions
Extend qa_gate.py with warn-only metrics that verify the Humanizer stage is producing natural results (pitch variance, high-frequency/breath energy, dynamic range).

  - **Add pitch-variance, HF-energy, and crest-factor QA metrics** _(claude)_ — Extend app/core/qa_gate.py with three new automated checks that never block export but flag results for the UI.
  - **Surface QA warnings as a caution badge in vocal_panel.py** _(antigravity)_ — Add a UI element showing the new QA metrics' warning state to the user after rendering.

## Milestone 4: Milestone 4: Factory reference stems + blind A/B UI
Add bundled owned/royalty-free reference vocal stems and extend the A/B comparison UI to support blind Raw / Humanized / Reference comparison, with a first-run fallback and custom override preference.

  - **Create factory reference asset loading + fallback logic** _(claude)_ — Backend support for locating bundled reference stems under /assets/factory_references/, detecting if they're missing, and supporting one optional custom global override path in preferences.
  - **First-run fallback modal for missing reference assets** _(antigravity)_ — A one-time modal prompting the user to supply reference files if the bundled factory_references assets are missing at launch.
  - **Extend A/B compare UI with Raw / Humanized / Reference blind toggle** _(antigravity)_ — Update ab_compare_view.py to add a three-way (or expandable) blind comparison including the new Humanized output and the factory/custom reference stem.

## Milestone 5: Milestone 5: RVC/Seed-VC stub
Add a visible but disabled placeholder control and config seam for future voice-conversion work, without implementing any inference.

  - **Add stubbed voice-conversion config field** _(claude)_ — Config/settings seam for the future RVC/Seed-VC wet-send feature, with no backend implementation.
  - **Add disabled 'Coming Soon' RVC slider to vocal_panel.py** _(antigravity)_ — Visible but disabled UI control communicating the planned voice-conversion feature.

## Milestone 6: Milestone 6: Integration testing and QA sweep
End-to-end test coverage for the full Humanizer pipeline addition and a bug sweep across the new stages.

  - **End-to-end pipeline test for Humanizer stage** _(jules)_ — Integration test exercising the full vocal_chain.py pipeline with the new humanizer pass enabled, verifying caching, ordering, and output validity.
  - **Bug sweep across new Humanizer stage and UI** _(jules)_ — Manual + automated sweep for edge cases across the new pitch drift, breath blend, QA warnings, A/B UI, and RVC stub.
