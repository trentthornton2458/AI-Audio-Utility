# Architecture

> Generated by Sauron from the discovery interview. Treat as the source of truth for this project.

## Stack
- Python 3.11/3.13
- PySide6 (existing UI framework)
- pedalboard (existing DSP)
- pyrubberband + external rubberband CLI binary (new, auto-downloaded)
- torch/torchaudio + resemble-enhance (existing neural stages)
- audio-separator / BS-RoFormer (existing stem separation)
- soundfile / numpy (existing audio I/O)
- pytest (existing test suite)

## Key Decisions
- New Humanizer stage (pitch drift + breath blend-back) is inserted after the existing enhance pass + QA-gated blend, immediately before remix/mastering — matches Counsel's stage diagram and avoids disturbing the already-tuned denoise/DSP/enhance ordering
- Pitch drift implemented via pyrubberband (±3-5 cent depth, 4-7Hz LFO rate) rather than a custom phase vocoder, for quality; the rubberband binary is auto-downloaded during the existing setup wizard flow (model_downloader.py pattern) instead of bundled in the installer, to keep GPL binary distribution and installer size manageable
- Breath/noise blend-back is automatic and fixed-amount (sourced from separation.py's residual/leftover signal), not user-controlled, to keep the UI simple — only pitch drift gets a user-facing slider
- QA gate (qa_gate.py) gains three new automated metrics (pitch-drift std-dev, >8kHz non-vocal energy, crest factor) that warn via a UI badge but never block export, consistent with the gate's existing cap-not-block philosophy
- A/B reference stems are committed as static owned/royalty-free assets under /assets/factory_references/ rather than fetched or user-supplied, with a one-time first-run fallback modal if the files are ever missing, and one optional custom global override in preferences (no per-track uploads)
- RVC/Seed-VC is intentionally scoped out of implementation this round — only a disabled 'Coming Soon' slider and a config field are added, so the architecture has a clear seam for future voice-conversion work without half-building it now
